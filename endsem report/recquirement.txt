1. OVERVIEW & CORE MISSION
--------------------------------------------------------------------------------
In the mid-term phase (completed 27 Oct 2026), our team completed Stages 1 to 5:
- Software baseline on CHB-MIT (17 seizures, 45.63 h control across 47 records).
- 100.0% sensitivity, 0.373 FA/h, 3.0 s median latency, 82.6 dB SQNR (B=16).
- Literature replication of Shoeb & Guttag (2010) (88.2%, 0.307 FA/h).
- Four core synthesizable Verilog modules designed (dwt_db4, svm_classifier,
  alarm_logic, uart_rx) with dwt_db4 bit-exact verified against hex vectors.

3. Stream EEG data from PC to Boolean Board over 230,400-baud UART and demonstrate
   live hardware seizure alarm assertion (LEDs, RGB LED, 7-segment display).

5. Author the Final Report (IEEE CVF template) with post-implementation hardware
   measurements, clear team work delineation (M1-M4), and defend in the viva.

3. HARDWARE & EQUIPMENT REQUIREMENTS
--------------------------------------------------------------------------------
A. RealDigital Boolean Board:
   - FPGA chip: AMD Spartan-7 XC7S50.
   - 100 MHz onboard oscillator (Pin F14).
   - Single Micro-USB cable connecting board JTAG/UART to PC.
   - Onboard USB-UART bridge (CP2102N / FTDI) providing virtual COM port.
   - Onboard peripherals used in demo:
     * 16 slide switches: SW[1:0] configure alarm persistence k (1, 2, 3, 5).
     * Pushbutton BTN0 (Pin J2): active-high synchronous system reset.
     * LED15 (Pin A4): Seizure Alarm strobe / pulse indicator.
     * RGB LED 0: Solid Green during normal streaming; Flashing Red on Seizure.
     * Dual 4-digit 7-segment display (8 digits total): Displays active channel,
       window counter, and latched seizure latency in seconds.

B. Host PC & Connectivity:
   - USB 2.0 / 3.0 port.
   - Silicon Labs CP210x Universal Windows Driver installed (or FTDI driver).
   - Verify COM port in Device Manager: e.g., `COM3`, `COM4`, or `/dev/ttyUSB0`.

--------------------------------------------------------------------------------
Per the course flier: "The work done by each team member must be clearly delineated
and the code written by each team member must be appropriately commented."

- MEMBER 1 (M1) - Data Engineering & Host Demo Lead:
  * Owner: CHB-MIT record parsing, manifest, and test vector extraction.
  * Develops `scripts/stream_eeg_uart.py` host Python streaming harness.
  * Validates UART packet protocol (0xAA header, 22 channels, Q1.15 data).
  * Measures end-to-end software vs hardware latency during board playback.

  * Owner: Causal IIR filter math, db4 DWT, and linear SVM training.
  * Conducts full-cohort fixed-point LORO re-evaluation in `src/fixedpoint.py`.
  * Generates `results/fixedpoint_loro_comparison.csv` proving B=16 parity.
  * Prepares mathematical derivations for viva defense (SQNR, group delay, shifts).

- MEMBER 3 (M3) - FPGA RTL Architecture & DSP48E1 Specialist:
  * Owner: Verilog RTL datapath modules in `rtl/`.
  * Implements `rtl/iir_biquad.v` and `rtl/feature_accumulator.v`.
  * Implements dynamic range wire-shifting for 38-bit Energy into DSP48E1.
  * Verifies cycle-accurate behavior via RTL testbenches (`tb_*.v`).

- MEMBER 4 (M4) - Vivado Synthesis, Implementation & Demo Lead:
  * Owner: Vivado project, pin constraints (`rtl/boolean_board.xdc`), and Tcl flow.
  * Closes timing at 100 MHz (setup slack WNS > 0, hold slack WHS > 0).
  * Generates bitstream (`top_seizure_detector.bit`) and programs Boolean Board.
  * Runs Vivado Power Analyzer (XPA) and extracts post-implementation LUT/BRAM/DSP.
  * Authors 7-segment display and LED controller (`rtl/seven_seg_controller.v`).
