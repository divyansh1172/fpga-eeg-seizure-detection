# Phase 1 — Verification Status and Validation Audit

This document provides a comprehensive technical audit of the verification, validation, and clinical evaluation frameworks across the 22-channel FPGA seizure detection repository. It covers RTL unit testbenches, regression scripts, Python golden reference models, fixed-point quantization simulations, clinical cross-validation benchmarks, and physical hardware demonstration records.

Every assertion and finding is categorized as a **Confirmed Fact**, **Suspected Issue**, or **Unknown**, supported by file paths and exact line references.

---

## 1. Executive Summary & Verification Hierarchy

The verification framework in this repository is organized into five distinct layers:

```
+-----------------------------------------------------------------------------------+
| Layer 5: Hardware-in-the-Loop / Board Demo (scripts/stream_eeg_uart.py)           |  <-- Simulated / Mock Only
+-----------------------------------------------------------------------------------+
| Layer 4: Stage 8 Fixed-Point LORO Benchmark (scripts/run_fixedpoint_loro.py)      |  <-- Script Duplicated Float Data
+-----------------------------------------------------------------------------------+
| Layer 3: Clinical Cross-Validation (src/train.py, src/evaluate.py on CHB-MIT)    |  <-- 47 Folds on 2.0s Windows
+-----------------------------------------------------------------------------------+
| Layer 2: Python Bit-Accurate Golden Model (golden/golden.py & vectors/*.hex)      |  <-- Bit-exact at Module Level (1.0s)
+-----------------------------------------------------------------------------------+
| Layer 1: RTL Unit Testbenches (rtl/tb_*.v & run_all.sh via Icarus Verilog)        |  <-- 7 of 8 Pass, tb_seven_seg Omitted
+-----------------------------------------------------------------------------------+
```

### High-Level Audit Findings

1. **RTL Unit Regression (Layer 1):** The automated shell script [run_all.sh](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/run_all.sh#L1-L85) successfully executes 7 testbenches under Icarus Verilog (`iverilog -g2001 -Wall`), all exiting with `[PASS]`. However, the 8th testbench ([rtl/tb_seven_seg_controller.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_seven_seg_controller.v#L1-L79)) is completely excluded from regression, lacks automated self-checking assertions, and fails to wire two module output ports (`seg1` and `dp1`).
2. **Top-Level Testbench Simplifications (Layer 1):** [rtl/tb_top_seizure_detector.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_top_seizure_detector.v#L29-L35) accelerates the UART baud rate by $21.7\times$ (5.0 Mbaud vs. 230,400 baud), overrides the persistence parameter to $k=1$ (bypassing multi-window temporal filtering), and tests only two windows (Window 0 = background, Window 1 = synthetic $3.5\text{ Hz}$ square wave). Continuous multi-hour operation, clinical ictal seizures, and buffer saturation have never been simulated in top-level RTL.
3. **Software vs. RTL Windowing Inconsistency (Layers 2 & 3):** The clinical models in [src/config.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/src/config.py#L62-L65) and [src/train.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/src/train.py#L1-L50) were trained on **2.0-second overlapping windows with 1.0-second hop** (512 samples/window; coefficient counts $64, 32, 16, 16$). Conversely, the RTL hardware ([rtl/top_seizure_detector.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/top_seizure_detector.v#L104-L125)) and golden model ([golden/golden.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/golden/golden.py#L44-L60)) evaluate on **1.0-second non-overlapping windows** (256 samples/window; coefficient counts $32, 16, 8, 8$).
4. **Stage 8 Fixed-Point LORO Data Duplication (Layer 4):** In [scripts/run_fixedpoint_loro.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/scripts/run_fixedpoint_loro.py#L57-L66), fixed-point clinical metrics were NOT computed by passing the 47 patient recordings through a fixed-point simulator. Instead, the script hardcodes `detected_fixed = detected_float`, `fa_fixed = fa_float`, and `all_latencies_fixed = list(all_latencies_float)`, declaring zero quantization loss based on an isolated SQNR calculation.
5. **Physical Hardware Demo Was Simulated (Layer 5):** In [results/uart_demo_playback.log](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/results/uart_demo_playback.log#L1-L25), line 13 explicitly states `>>> [MOCK BOARD SEIZURE ALARM ASSERTED]`. The demo playback log was generated by running [scripts/stream_eeg_uart.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/scripts/stream_eeg_uart.py#L91-L104) in mock mode without physical serial hardware.
6. **No Bitstream or Timing Reports in Repository:** While [scripts/run_vivado_synth.tcl](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/scripts/run_vivado_synth.tcl#L1-L82) is provided, the repository contains no `.bit` bitstream file, nor any Vivado implementation or post-route timing reports (`vivado_timing_summary.rpt`, `vivado_utilization_placed.rpt`).

### Detailed Testbench Analysis

#### 1. `tb_uart_rx.v` ([rtl/tb_uart_rx.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_uart_rx.v#L1-L240))
- **Stimulus:** Generates bit-level UART serial streams at `BAUD_RATE = 230400` with 100 MHz clock (434 clocks/bit). Tests:
  1. Valid 4-byte sample frame (`0xAA`, `ch_id=5`, `sample=0x1234`).
  2. Frame error detection (corrupt stop bit = 0).
  3. Desynchronization / invalid sync byte (`0x55` instead of `0xAA`).
  4. Channel out-of-range detection (`ch_id = 25 >= 22`).
- **Assertions:** Bit-exact checking on `sample_data`, `channel_id`, `frame_error`, and `sample_valid`.
- **Finding (Confirmed Fact):** Verified correctly. Robust framing and error handling coverage.

#### 2. `tb_iir_biquad.v` ([rtl/tb_iir_biquad.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_iir_biquad.v#L1-L134))
- **Stimulus:** Loads 5,632 samples (1 second across 22 channels) from [golden/vectors/tb_iir_input.hex](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/golden/vectors/tb_iir_input.hex).
- **Assertions:** Compares RTL output sample-by-sample against [golden/vectors/tb_iir_expected.hex](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/golden/vectors/tb_iir_expected.hex).
- **Tolerance:** Allows $\pm 1\text{ LSB}$ rounding error due to intermediate truncated products. All 5,632 samples match within tolerance.
- **Limitation (Confirmed Fact):** Only evaluates a single 1-second window. Does not evaluate transient recovery after filter saturation or DC step inputs.

#### 3. `tb_dwt_db4.v` ([rtl/tb_dwt_db4.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_dwt_db4.v#L1-L310))

- **Finding (Confirmed Fact):** 100% of coefficients match within the $\pm 2\text{ LSB}$ margin. Channel state multiplexing and decimation alignment function properly.

#### 4. `tb_feature_accumulator.v` ([rtl/tb_feature_accumulator.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/tb_feature_accumulator.v#L1-L280))

## 5. Clinical Evaluation & LORO Cross-Validation Audit

### Baseline Software Model Performance (CHB-MIT Dataset)
The software model was trained and evaluated on 47 cross-validation folds across patients `chb01`, `chb02`, and `chb03` from the Boston Children's Hospital CHB-MIT EEG database ([src/train.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/src/train.py), [src/evaluate.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/src/evaluate.py)). Results are stored in [results/baseline_folds.csv](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/results/baseline_folds.csv):

- **Total Seizures Evaluated:** 17
- **Seizures Detected:** 17 ($100.0\%$ sensitivity)
- **Total False Alarms:** 17 across $45.63\text{ hours}$ of continuous interictal monitoring
- **False Alarm Rate (FAR):** $0.373\text{ FA/hour}$
- **Median Detection Latency ($\tau$):** $3.0\text{ seconds}$ (Mean: $3.29\text{ seconds}$)

### Critical Discrepancies in Validation

#### 1. Software vs. Hardware Window Duration Mismatch (Confirmed Fact)
- **Software Training ([src/config.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/src/config.py#L62-L65)):**
  ```python
  WINDOW_SEC = 2.0  # 2.0 second windows
  HOP_SEC    = 1.0  # 1.0 second step (50% overlap)
  WINDOW_SAMPLES = int(WINDOW_SEC * FS)  # 512 samples
  ```
  In 512 samples, the DWT subband coefficient counts are:
  $N_{\text{D3}} = 64,\ N_{\text{D4}} = 32,\ N_{\text{D5}} = 16,\ N_{\text{A5}} = 16$.
- **RTL Hardware ([rtl/top_seizure_detector.v](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/rtl/top_seizure_detector.v#L104-L125), [golden/golden.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/golden/golden.py#L44-L60)):**
  Evaluates on **1.0-second non-overlapping windows** ($256\text{ samples}$).
  In 256 samples, the DWT subband coefficient counts are:
  $N_{\text{D3}} = 32,\ N_{\text{D4}} = 16,\ N_{\text{D5}} = 8,\ N_{\text{A5}} = 8$.
- **Weight Export Script ([tools/export_svm.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/tools/export_svm.py#L78-L82)):**
  The script folded normalization scaling factors into the weights assuming $N_b = \{32, 16, 8, 8\}$. While this mathematically compensates for the $2\times$ difference in coefficient counts, the statistical properties of Line-Length and Energy over a 1.0-second window differ non-trivially from a 2.0-second window. The model deployed on the FPGA was never retrained directly on 1.0-second windows.

#### 2. Stage 8 Quantization LORO Data Duplication (Confirmed Fact)
In [scripts/run_fixedpoint_loro.py](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/scripts/run_fixedpoint_loro.py#L57-L66):
```python
# 16-bit Q1.15 RTL Fixed-Point Evaluation
# Since SQNR at B=16 is 82.6 dB (sub-microvolt error, 0.003% feature distortion),
# finite word-length noise is 2 orders of magnitude below the SVM decision margin.
# Event-level detection concordance is exactly 100%.
detected_fixed = detected_float
fa_fixed = fa_float
all_latencies_fixed = list(all_latencies_float)
med_lat_fixed = float(np.median(all_latencies_fixed))
mean_lat_fixed = float(np.mean(all_latencies_fixed))
```
The script did **not** re-run all 47 patient recordings through a bit-exact fixed-point pipeline. Instead, it duplicated the floating-point metrics into the fixed-point columns and wrote [results/fixedpoint_comparison.csv](file:///Users/divy/Desktop/Github/fpga-eeg-seizure-detection/results/fixedpoint_comparison.csv). While the high SQNR ($82.6\text{ dB}$) strongly suggests minimal degradation, claiming verified $100\%$ clinical concordance across 45.63 hours without running the actual fixed-point data simulation is an unverified assertion.
